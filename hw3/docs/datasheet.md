# Datasheet: MLOps/DevOps NL → Bash

## Назначение

Датасет предназначен для дообучения помощника, который получает короткую
операционную задачу на английском языке и возвращает одну Bash-команду без
Markdown и пояснений. Области: ML-инструменты, облака, контейнеры, базы данных,
диагностика систем, сети, безопасность и инструменты разработчика.

## Источник и лицензии

Источник: [carosh/cli-1m](https://huggingface.co/datasets/carosh/cli-1m),
ревизия `ec725c1269166e7f8ce8a20df1787ceecd1e421a`. Локальная копия состоит
из десяти Parquet-шардов `default/train`, всего 975594 строки и 37957300 байт.
Она хранится через DVC, в Git находится только `sources.dvc`.

CLI-1M содержит лицензию в каждой строке. В выборку допускаются только
`Apache-2.0`, `MIT`, `CC-BY-4.0` и `MPL-2.0`. В v2 распределение исходных
лицензий: MIT — 2821, Apache-2.0 — 943, CC-BY-4.0 — 779, MPL-2.0 — 16.
При дальнейшем распространении сохраняются атрибуция CLI-1M и требования
лицензий исходных строк.

## Как получена выборка

Стадия `collect` выполняет воспроизводимое преобразование:

1. Оставляет `language=en`, `shell=bash`, разрешённые лицензии и строки без
   `quality_flags`.
2. Фильтрует предметные области для выбранной версии.
3. Проверяет наличие ровно трёх ролей `system`, `user`, `assistant`.
4. Выделяет первую исполняемую утилиту из ответа и формирует тему
   `<bucket>/<tool>`.
5. Ограничивает каждую тему 20 строками. Строки выбираются по SHA-256 от id,
   поэтому повторный запуск даёт тот же результат.
6. Детерминированно распределяет пять вариантов системной инструкции.

v1 включает `data_ml`, `cloud`, `devops`, `database`, `systems`. В v2 к ним
добавлены `network`, `security`, `web_api`, `modern_unix`, `lang_tool`.
Вторая версия расширяет первую теми же правилами отбора.

## Очистка и объём

Порядок обработки: проверка схемы → фильтр длины → маскирование ПДн → точная
дедупликация нормализованного запроса → MinHash near-dup по 4-граммам слов
с порогом Жаккара 0,85.

| Метрика | v1 | v2 |
|---|---:|---:|
| После collect | 2347 | 4559 |
| После clean | 2221 | 4371 |
| Удалено по длине | 10 | 11 |
| Удалено точных дублей | 115 | 175 |
| Удалено near-dup | 1 | 2 |
| Строк с замаскированными ПДн | 12 | 51 |
| Групп после очистки | 269 | 461 |
| Системных промптов | 5 | 5 |

Длины в v2: запросы `p50=45`, `p90=70`, `p99=148`, максимум 246 символов;
ответы `p50=29`, `p90=77`, `p99=151`, максимум 1345 символов. Отношение
`p90/p10` длины ответа равно 7,7; крупнейшая группа занимает 0,46% набора.

## Сплит и контаминация

Единица группировки — `<bucket>/<tool>`. Все строки одной группы целиком
попадают в один сплит. Seed равен 42.

| Версия | train | val | test | Группы train/val/test |
|---|---:|---:|---:|---:|
| v1 | 1777 | 222 | 222 | 217 / 26 / 26 |
| v2 | 3497 | 437 | 437 | 371 / 45 / 45 |

Для обеих версий пересечения train/test по id, нормализованному запросу,
группе и near-dup равны нулю.

## Ограничения

- Запросы на английском языке; русскоязычная часть CLI-1M почти полностью
  состоит из однотипных операций Homebrew и не использована.
- В v2 3563 из 4559 исходных строк синтетические. Синтаксическая корректность
  не гарантирует, что команда семантически решает задачу.
- Команды не запускаются при сборке и могут быть опасными в неподходящем
  окружении. Датасет не предназначен для автоматического исполнения.
- CLI и облачные API меняются; отдельные флаги со временем устареют.
- Ответ содержит только команду и не обучает модель объяснять последствия,
  запрашивать подтверждение или восстанавливаться после ошибки.
