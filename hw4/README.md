# ДЗ 4 — токенизация и маска лосса

Вход — датасет CLI v2 из ДЗ3 (`hw3`, коммит `22caba5`):
3497 примеров train и 437 val. Используется модель из ДЗ1,
заданная в `params.yaml`; веса для этой стадии не нужны.

## Запуск

Из папки `hw4`, после восстановления данных ДЗ3:

```bash
mkdir -p data
cp ../hw3/data/train.jsonl ../hw3/data/val.jsonl data/
uv sync --locked
make tokenize
make check
```

`make check` сам повторяет токенизацию. Все девять проверок должны
пройти; отпечаток исходного `tests/check.sh` — `f2002c8c9519`.
Скрипт проверки не изменён. Для сдачи нужно записать видео этого запуска.

## Результат

- [Разбор четырёх дефектов](docs/defects.md).
- [Сгенерированный отчёт](docs/tokenize_report.md).
- [Метрики](metrics/tokenize.json).
- `data/tokenized/{train,val}.pt`: примеры с `input_ids`, `attention_mask`
  и `labels`; данные и тензоры исключены из Git.

Единый шаблон находится в `src/prompt.py`, промпт маскируется значением
`-100`, коллатор динамически дополняет батч слева.
`max_seq_len=320` сохраняет все ответы своего датасета.
Необязательный packing выключен. `dvc.yaml` описывает отдельную стадию
`tokenize` с входами, кодом, параметрами, выходами и метриками.
Отчёт и метрики обновляются только запуском стадии.
