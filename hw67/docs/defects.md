# Четыре дефекта учёта экспериментов

1. **Все кандидаты попадали в один run.** `start_run` охватывал весь цикл,
   поэтому параметры первого кандидата оставались общими, а метрики и модель
   перезаписывались последующими. Создание дочернего run перенесено внутрь
   цикла: у каждого кандидата своё имя, параметры, кривые и пакет модели.
   Проверки 1, 3 и 4 сопоставляют шесть отдельных runs с конфигурациями.
2. **Артефакты терялись при пересоздании MLflow.** PostgreSQL уже имел том,
   но `/mlartifacts` находился в слое контейнера. Добавлен именованный том
   `artifacts:/mlartifacts`. `make check-storage` записывает случайный probe,
   пересоздаёт только MLflow и проверяет SHA256 скачанного файла.
   Доказательство сохраняется в `metrics/storage-check.json`; проверка 8
   повторно скачивает этот же артефакт.
3. **Хеши train/val отбрасывались.** `provenance()` уже вычисляла SHA256,
   но фильтр `data_` удалял их перед логированием. Теперь все версии
   сохраняются в тегах родителя и каждого кандидата. Проверка 2 сравнивает
   хеши текущих файлов с runs. Исходные JSONL, тензоры, полный индекс
   вопросов и golden закреплены в DVC. `data/provenance.json` связывает
   исходники и код ДЗ 4 с тензорами, включая порядок всех 3497 train id.
4. **Порог loss обходился при регистрации.** `promote()` считала отношение
   loss, но не вызывала существующую `gate()`. Теперь gate выполняется до
   первой записи в реестр: проверяет FINISHED, конечность метрик, положительный
   base loss и `final/base <= threshold`. Проверка 6 требует отказа при
   нулевом пороге. Регистрация создаёт `candidate`; смена `champion` проходит
   только через отдельный гейт качества `make promote`.

Дополнительно реализованы требуемые `score` и `quality_gate`.
Scorer учитывает все вопросы, сопоставляет ответы по id, проверяет строгий
JSON, не принимает повтор JSON-ключа и сохраняет ошибки генерации.
Gate сверяет версии протокола, id, состав срезов, counts и конечность долей;
запрещает ошибки генерации и любое ухудшение заданных метрик, требует
прохождения всех behavioral-кейсов. Тесты преподавателя не изменены:
отпечаток `c42ac7788026`.
